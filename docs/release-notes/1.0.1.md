# Meco v1.0.1

A maintenance release that fixes file preview on Windows.

## What's fixed

### PDF and HTML files no longer open blank on Windows

On Windows, opening a PDF in the canvas showed an empty page, and an HTML file opened through **Open in browser** behaved the same way. The files themselves were fine — the same PDF opened normally in WPS, Edge or any other reader, and the same file previewed correctly on macOS.

The cause was in how Meco turned a file's path into the address it hands to the built-in viewer. On Windows that address came out malformed, so the viewer was never actually given the file: the page stayed blank, with no error message to explain why. Every PDF and every HTML file opened this way was affected — it had nothing to do with the file's name, size or contents.

Meco now builds that address correctly on every platform.

As a side effect, files whose names contain `#` now preview correctly on macOS as well. That case was broken there too, but it was far less visible because it only affected a handful of file names.

Nothing else changed. Images, Word, Excel, Markdown, code and every other preview path behave exactly as they did in 1.0.0.

```bash

cd heyoo-meco
npm install
npm run cap:sync
npx cap open ios
# In Xcode: select your signing team under Signing & Capabilities, then run on your device.
```

```bash
git clone -b public https://github.com/LangInOS/heyoo-meco.git
cd heyoo-meco
npm install
npm run build:mac      # macOS dmg + zip (Apple Silicon)
npm run build:win      # Windows NSIS installer
npm run build:linux    # Linux AppImage + deb
```

# Meco v1.0.1（中文）

一个修复 Windows 文件预览问题的维护版本。

## 修复内容

### Windows 上 PDF 与 HTML 文件不再打开为空白

在 Windows 上，从画布打开 PDF 会显示成一个空白页面；通过**在内置浏览器打开**打开的 HTML 文件也是同样的情况。文件本身没有问题——同一个 PDF 用 WPS、Edge 或其他阅读器都能正常打开，在 macOS 上用 Meco 预览也正常。

问题出在 Meco 把文件路径转换成地址、交给内置查看器的那一步。在 Windows 上这个地址是畸形的，查看器实际上从未拿到文件：页面就停在空白状态，也没有任何错误提示说明原因。所有以这种方式打开的 PDF 和 HTML 文件都会中招——与文件的名字、大小、内容都无关。

现在 Meco 在各平台上都会正确地构造这个地址。

顺带修好的一个问题：文件名里含 `#` 的文件，在 macOS 上现在也能正常预览了。这个情况在 macOS 上原本也是坏的，只是受影响的文件名很少，所以一直没被发现。

除此之外没有其他改动。图片、Word、Excel、Markdown、代码等其余预览路径与 1.0.0 完全一致。
