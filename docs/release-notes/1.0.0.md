# Meco v1.0.0

Meco is a local-first AI workstation where agents divide the work, hand it over, build up memory and stay on duty — while you set the direction and make the calls. Everything runs on your own machine: your files stay local, your keys stay yours, and team data only moves when a result is published.

This is the first public release of Meco.

## Highlights

### Your everyday AI workbench

- **Chat + canvas**: reports, code, web pages, terminals and Word / Excel / PowerPoint / PDF files open right beside the conversation. Select a passage, add a note, and the agent knows exactly what you mean.
- **Capabilities on demand**: the “+” menu turns on web control, team collaboration, the AI terminal, OCR and self-operation only when you need them. Attach local files and folders directly — nothing is uploaded.
- **Coding**: choose Claude Code, Codex and other engines; see exactly what changed in the changes view, then start a quick review or a multi-role team review with one click.
- **AI browser and terminal**: the agent drives a real browser and a real terminal while you watch. Take over or stop it at any time.
- **Office documents**: built-in document skills and a bundled runtime create and edit Word, Excel, PowerPoint and PDF files — no dependency hunting.
- **Knowledge base and memory**: point it at files, folders, PDFs and Office documents; answers cite their sources. Chats in the same space share memory — current state, history and topics — so a new conversation never starts from scratch.
- **Connected conversations**: open one chat and ask “how are the other conversations going?” — it checks each one and sums things up. The agent can also manage spaces, digital humans and settings for you.
- **Bring your tools**: connect MCP servers and skills in one click, compatible with the Claude Code MCP and Skills ecosystem.
- **Multiple models, multiple accounts**: any Anthropic- or OpenAI-compatible API, plus several ChatGPT, Claude and GitHub Copilot accounts signed in at once. Switch the model and thinking effort per conversation.

### Digital humans and teams

- **Digital humans**: AI members that stay on duty — on a schedule or on events, with an optional mainland-China working-day calendar (holidays and make-up workdays included), chat reminders, one-click install from the store, or creation from a single sentence.
- **Teams in one sentence**: “Put together a team to research these three products” — research, fact-checking and writing split themselves up. Say “keep this team” to make it permanent, schedules included.
- **Teams across computers**: colleagues join with their own digital humans, each running on its owner's machine. Data stays on each machine; only published results move through the team, and every digital human's permissions are set by its owner.
- **See the work happen**: the team workspace shows tasks, progress, hand-offs and results. Teammates sort things out among themselves and only bring you what the team cannot decide.
- **Digital human store**: ready-made digital humans for research, daily digests, monitoring and social operations — install and go. Organizations can host a private store.
- **Browser actions**: the agent decides, scripts execute. One concrete operation on one platform becomes a reusable script; ready-made actions cover major social platforms, and private actions can be written for internal systems.

### Hand off work from anywhere

- **Phone and remote web**: reach the Meco on your desk from anywhere — hand off tasks, upload material, download results.
- **IM integration**: Feishu, WeChat and WeCom. Hand work to a digital human from the chat window you already use; behind it can be a whole team.
- **Decide in IM**: results land in the chat; when something needs your call, reply once and the work moves on.

## Downloads

| Platform | File | Notes |
| --- | --- | --- |
| macOS (Apple Silicon) | `Meco-1.0.0-arm64.dmg` | Not code-signed. First launch: right-click the app → **Open**, or run `xattr -cr /Applications/Meco.app`. |
| Windows 10/11 (x64) | `Meco-1.0.0-setup.exe` | Not code-signed — SmartScreen may warn; choose **More info → Run anyway**. |
| Linux (x64) | `Meco-1.0.0.AppImage` / `.deb` | Make the AppImage executable (`chmod +x`) and run. |
| Android | `Meco-1.0.0-android.apk` | Debug-signed build; allow installing apps from unknown sources. |
| iOS | Build from source | No signed iOS build is distributed with this release — see the steps below. |

### Build iOS from source

```bash
git clone -b public https://github.com/LangInOS/heyoo-meco.git
cd heyoo-meco
npm install
npm run cap:sync
npx cap open ios
# In Xcode: select your signing team under Signing & Capabilities, then run on your device.
```

### Build the desktop apps from source

```bash
git clone -b public https://github.com/LangInOS/heyoo-meco.git
cd heyoo-meco
npm install
npm run build:mac      # macOS dmg + zip (Apple Silicon)
npm run build:win      # Windows NSIS installer
npm run build:linux    # Linux AppImage + deb
```

# Meco v1.0.0（中文）

Meco 是一款本地优先的 AI 工作台：智能体之间自己分工、交接、积累记忆并持续值守，你负责定方向、做决定。一切运行在你自己的电脑上——文件不出本机，密钥归你保管，团队数据只在发布结果时才会流动。

这是 Meco 的首个公开发布版本。

## 核心能力

### 你的日常 AI 工作台

- **对话 + 画布**：报告、代码、网页、终端、Word / Excel / PPT / PDF 就在对话旁边打开；划选一段加个批注，AI 精确知道你指的是什么。
- **能力按需开启**：输入框的 “+” 菜单在需要时打开网页操控、团队协作、AI 终端、OCR 和自我操作；直接附加本地文件和文件夹，内容不上传。
- **编程**：可选 Claude Code、Codex 等引擎；在改动视图里看清 AI 改了什么，一键发起快速评审或多角色团队评审。
- **AI 浏览器与终端**：AI 当着你的面操作真实浏览器和终端，你随时可以接管或叫停。
- **Office 文档**：内置文档技能与运行时，直接产出和编辑 Word、Excel、PPT、PDF，不必先装一堆依赖。
- **知识库与记忆**：把文件、文件夹、PDF、Office 文档放进知识库，回答时带来源引用；同一空间内的对话共享记忆——当前状态、历史、话题分层组织，新对话不必从零开始。
- **互通的对话**：新开一个对话问“其他对话进展如何”，它会逐个查看并汇总；AI 还能帮你管理空间、数字人和设置。
- **接上你的工具**：一键接入 MCP 服务与技能，兼容 Claude Code 的 MCP 和 Skills 生态。
- **多模型、多账号**：任意 Anthropic / OpenAI 兼容 API，同时登录多个 ChatGPT、Claude、GitHub Copilot 账号；每个对话可单独切换模型与思考力度。

### 数字人与团队

- **数字人**：持续值守的 AI 成员——按日程或事件运行（可选仅中国大陆工作日，含节假日与调休），可在对话里提醒，从商店一键安装，或一句话创建。
- **一句话组队**：在任何空间里说“组个团队调研这三款产品”，调研、事实核查、撰写自动分工；说“保留这个团队”即可长期使用，还能给整个团队排班。
- **跨电脑协作**：同事用自己的数字人加入你的团队，各自运行在主人的电脑上；数据留在本机，只有发布到团队的结果才会流转，每个数字人的权限由其主人设定。
- **看着工作发生**：团队工作区展示任务、进度、成员交接与结果，只有团队定不了的事才会来找你。
- **数字人商店**：调研、日报、监控、社媒运营等现成数字人，装上就用；组织可以自建私有商店。
- **浏览器操作**：AI 决策、脚本执行。把某个平台上的一个具体操作写成可复用的 .js 脚本；主流社交平台已有现成操作，内部系统可以编写私有操作。

### 随时随地交接工作

- **手机与远程网页**：随时随地连上你电脑上的 Meco——派任务、传素材、收结果。
- **IM 集成**：飞书、微信、企业微信。在惯用的聊天窗口里把工作交给数字人，它背后可以是一整个团队。
- **在 IM 里做决定**：结果送到聊天里，需要你拍板时回一句话，工作继续推进。
