# Meco 学员速查卡（打印这一页）

## 三句话记住 Meco

1. **它会干活**：你说一句话，它查资料、写文件、交成品。
2. **数据在你电脑里**；删除、发送、付款它会先问你。
3. **重复的事交给数字人**；出门用手机遥控。

## 把活说清楚的公式

> **要什么 ＋ 在哪 ＋ 什么标准**

例：「把**下载文件夹里的发票**（在哪）**按月份整理成表格、加一列金额**（要什么＋标准）。」

说得不够清也没关系——它会先问你，选一个选项就行。

## 常用说法

| 场景 | 就这么说 |
|---|---|
| 修改成果 | 「标题换成…」「加一列…」「换种风格重写」 |
| 让它停 | 「停，先别动」 |
| 补充要求 | 随时插话，不用等它跑完 |
| 问进度 | 「其他几个对话进行得怎么样了？」 |
| 处理请示 | 微信/群里回「同意」或「先不要」 |

## 五个入口（左侧导航）

| 入口 | 干什么 |
|---|---|
| 会话 | 日常派活 |
| 数字人 | 定时任务的管理面板 |
| 知识库 | 喂资料，回答带出处 |
| 商店 | 现成数字人，一键上岗 |
| 任务 | 看所有进行中的事 |

## 出问题了？

- **它要删/要发东西** → 都是先问你，同意/拒绝即可，事后有记录可查。
- **文件找不到** → 把完整位置说给它。
- **免费额度用完** → 设置 → AI 模型，换自己的服务；费用付给服务商，Meco 不加价。
- **微信掉线** → 个人微信是非官方协议，重新扫码；长期用换企业微信。
- **还是不行** → 问部门 Meco 联络人 → 查《使用手册》常见问题。

## 一周上手节奏

第 1 天说第一句话 → 第 1 周每天派一件真活 → 第 2 周建空间、喂知识库 → 第 3 周装第一个数字人 → 第 4 周连微信、手机遥控。详见《上手练习卡》。
