## 一、Meco 是什么

Meco 是**装在你自己电脑里的 AI 工作台**。简单说：**你说一句话，AI 替你干完**——它自己拆解步骤、查资料、读写你电脑里的文件、写出成品；生成的文件就在旁边画布里，点开就能看、开口就能改；拿不准的事，它会先问你。

它和你用过的网页版 AI 聊天不同：网页版只能「聊」，Meco 能「做」——操作浏览器、读写本地文件、定时干活，干完主动汇报。

三个前提，先记住：

1. **不需要懂技术**：安装是双击下一步，登录是微信扫码，使用就是打字说话。
2. **数据留在你手里**：纯本地应用，官方没有存储用户数据的服务器；聊天记录和文件都在你自己电脑上。
3. **主动权在你**：AI 干活的每一步都看得见；删除、发送、付款这类敏感操作先问你；重要决定永远由你拍板。

## 二、安装与登录

### 2.1 下载安装（和装微信一样）

| 你的电脑 | 下载哪个 | 系统要求 |
|---|---|---|
| Mac（Apple 芯片） | .dmg（Apple Silicon） | macOS 11 以上 |
| Mac（老款 Intel） | .dmg（Intel） | macOS 11 以上 |
| Windows 电脑 | .exe | Windows 10 以上 |
| Linux 电脑 | .AppImage | Ubuntu 20.04 以上 |

- **Mac**：打开 .dmg，把 Meco 图标拖进「应用程序」；首次打开如提示「来自未知开发者」，右键点图标选「打开」。
- **Windows**：双击 .exe，一路「下一步」。
- 分不清 Mac 芯片：点屏幕左上角 →「关于本机」——「芯片」写着 Apple M 几选 Apple Silicon；写着「处理器 Intel」选 Intel。

**安装提示处理**：

- Mac 提示「已损坏，无法打开」→ 系统设置 → 隐私与安全性 → 点「仍要打开」。
- Windows 提示病毒或未知发布者 → Meco 是开源软件，安装包尚未购买数字签名，属正常提示；请从官方发布页下载确保来源可靠，然后选「仍要运行」。
- 公司电脑一般由 IT 统一安装分发，开箱即用，无需自己操作。

### 2.2 连接 AI 大脑（三种方式）

Meco 本身免费开源，干活需要接入一个 AI 模型服务：

1. **微信扫码，用免费额度（推荐先用这个）**：打开 Meco 微信扫一扫登录即可，附带免费体验额度，开箱就能用。
2. **使用自己的 AI 服务账号**：设置 → AI 模型 → 选服务商 → 填入密钥。密钥只保存在你自己电脑里，Meco 不会上传；请勿把密钥发给别人或发到网上。
3. **企业私有化接入**：装在公司内网、统一配置公司模型服务，数据不出内网；由 IT 统一操作。

免费额度用完后，换成方式二；费用直接付给 AI 服务商，Meco 不加价、不抽成。

## 三、认识主界面

- **左侧导航**：会话 / 数字人 / 知识库 / 商店 / 任务 / 设置。
- **中间对话框**：你派活的地方，像跟同事说话一样打字。
- **右侧工件栏 + 画布**：AI 每生成一个文件就出现在工件栏，点一下在画布中打开。
- **底部**：切换模型、发送；「+」按需开启额外能力；「知识」按钮把知识库加载进当前对话。

### 空间：给每件事一个独立抽屉

一个项目一个空间。工作区是一个项目的独立上下文：包含该项目的文件夹、对话、知识库、数字人以及已安装的技能。

- 随手问、临时小活 → 用默认空间，不用建。
- 一件事要持续做 → 点「新建工作区」起个名字（如「小红书账号」「店里的事」）。
- 要处理电脑里某个文件夹 → 把空间指向它，AI 就能在里面干活。
- 每个空间有自己的记忆：AI 记得这个项目聊过什么，换个聊天不用从头介绍。

## 四、日常干活：对话 + 画布

### 4.1 怎么把活说清楚

不用记任何指令格式。说得越具体，AI 干得越准：

- **说清楚要什么**：「写一份上周的销售总结」比「帮我总结」效果好。
- **说清楚在哪**：「把下载文件夹里的发票按月份整理」比「整理发票」效果好。
- **说清楚标准**：「语气正式一点」「控制在 500 字内」「用表格」。
- **说得不够清也没关系**：AI 会先问你，而不是猜一个方向埋头做完。

第一次让它动某个文件夹，最好在旁边看一眼；不确定要不要删，先让它列出来给你确认。

### 4.2 看成果：画布

AI 生成的东西都出现在右侧工件栏，点一下在画布中打开：

| 生成的东西 | 你能做什么 |
|---|---|
| 文档（Markdown） | 像文章一样阅读 |
| 表格（CSV） | 像 Excel 一样翻看 |
| 图片 | 放大缩小查看 |
| 网页 | 直接打开实时预览 |
| 代码 | 高亮显示 |

文件存在你电脑上你指定的位置，大小就是文件本身大小，随时可自己清理。

### 4.3 看完想改？直接说

不用另存、不用导出、不用学编辑操作，回到对话框开口就行：

- 「标题换成 XX」
- 「表格加一列运费」「按金额从高到低排」
- 「这个网页的按钮改成红色」
- 「语气正式一点」「换一种风格重写」

AI 改完，画布内容同步更新。可以在一轮对话里连续提多个修改要求，它都记得上文。

### 4.4 过程看得见，随时能插手

- 它在查哪个网页、读到哪一行、生成了什么文件，界面上都看得见。
- 随时可以插话：补充要求、喊停、换方向，不用等它跑完。发现它找错文件夹或理解偏了，立刻说「停」。
- 把截图、照片直接拖进对话框，它能看懂图片内容（识别截图里的表格、看懂设计稿、解释照片里的文字）。
- 每一次做了什么都有记录可回看。

### 4.5 拿不准，它会先问你

信息不够时，它会停下来给你选项（比如「我提供内容」或「用示例模板」），选一个点提交它就继续。**删除文件、发送消息、提交表单这类敏感操作，默认先征求你的同意。**

## 五、知识库与记忆

- 把文件、文件夹、PDF、Office 文档放进知识库，聊天时 AI 自动引用并标注出处，便于核对。
- 用输入框的「知识」按钮把知识库加载进当前对话，或附加给数字人。
- 同一空间的多个聊天共享记忆，按「当前状态 / 历史 / 专题知识」分层整理——换一个新聊天不用从头介绍背景。

### 适合把什么放进知识库

判断标准很简单：**凡是希望 AI 回答时「按你们自己的资料来说话」的内容，都值得放进去。**

- **客服 / 售前**：产品手册、常见问答（FAQ）——回答自动引用原文并标注出处，客户问到细节也不慌。
- **新人上手**：公司制度、流程文档——随问随答，不用在群里翻聊天记录找文件。
- **项目协作**：方案、会议纪要——放进对应空间的知识库，换一个聊天不用重讲背景。
- **数字人值守**：把知识库附加给数字人，它就按你的资料回答和干活，而不是凭通用印象编。

## 六、数字人：按时间表自动上班的 AI

### 6.1 是什么

你告诉它做什么、多久做一次，它就定时定点自己干，不需要你守在电脑前——就像给员工排一张班表。

常见用途：

- **内容运营类**：定时回复小红书、B站、知乎的评论和私信；按排好的时间发布内容；盯着品牌讨论，每天一份小结。
- **巡检提醒类**：定时检查店铺后台、业务数据，有异常立刻提醒你。
- **报告汇总类**：早报、周报、会议纪要自动生成，按你定的时间送到你手里。

### 6.2 从商店安装（推荐）

1. 打开「商店」页面，浏览或搜索，比如「日报助手」。
2. 点「安装」，按提示填配置——通常就是账号信息和执行时间（如每天 09:00）。
3. 完成，数字人自动开始按计划运行。

装完能改：「把它改成每天两次巡检」，它自己调整。企业也可以部署内部私有商店，把适合自己公司的数字人共享给全体同事。

### 6.3 自己创建

在「数字人」页点「+ 创建数字人」，或者直接在对话里说一句话，比如「我想让 AI 每天早上 9 点检查店铺后台，有差评就微信提醒我」，它会帮你搭好。

### 6.4 怎么管

都在数字人面板里：暂停/继续、改时间、改任务、看执行记录、下线。它拿不准的事会来问你；连了微信/企业微信的话，回一句「同意」它就继续。

**务实的建议**：先让数字人跑「只读 + 汇报」的活（查数据、做汇总、发通知给你），稳定跑一两周后再逐步放开「会对外产生影响」的动作（自动回复、自动发布）。每一步放权，都有执行记录可回查。

## 七、微信 / 企业微信：把 AI 装进聊天工具

入口：**设置 → 消息通道**。在熟悉的聊天窗口里派活、收结果、批请示。

| | 个人微信 | 企业微信 |
|---|---|---|
| 适合 | 个人使用，零门槛 | 团队协作，更稳定 |
| 连接方式 | 扫码即可 | 需企业微信管理员配置机器人 |

**企业微信四步接通（约五分钟，管理员操作）**：

1. 在企业微信后台创建一个机器人。
2. 把机器人的地址和密钥填进「设置 → 消息通道 → 企业微信智能机器人」。
3. 把机器人拉进需要的群，显示连接成功即完成。
4. 群里 @机器人派活：「@Meco 把这周的客服记录汇总一下」，结果回到群里。

团队使用建议：建一个「AI 工作群」汇聚通知类数字人的输出；各业务群分别拉机器人，分工明确。AI 的请示直接在群里回复，值班的人都能看到。

> **重要**：个人微信接入使用非官方协议，连接稳定性受微信策略影响，偶尔可能需要重新扫码；**建议用小号或工作号专门连接**；正式、长期使用建议改用企业微信。

## 八、手机远程：走到哪，遥控到哪

**电脑上**：设置 → 远程访问 → 打开「启用远程访问」→ 设一个 6 位 PIN 码（这是你的连接密码，别用生日）。

**手机上**：装 Meco App → 添加服务器 → 填电脑显示的连接地址（同一 Wi-Fi 下会自动发现）→ 输 PIN 码。连上后手机界面和电脑上完全一样：对话、数字人、画布都在。

- **出门在外**：在「远程访问」里开启「外网访问」，任何网络下都能连，同样需要 PIN 码，连接全程加密。
- 多台电脑可保存切换，像换聊天窗口；不想被连了，关掉开关立刻生效。
- 注意：「远程访问」「系统」「高级」这三项设置只在电脑客户端里有，网页版看不到。

## 九、安全与使用边界

1. **数据在你手里**：纯本地应用，聊天记录和文件不出你的电脑；只有 AI 干活需要联网时，才按你的设置访问相应服务。涉密资料请放在公司内网部署的实例里处理。
2. **密钥只存本机**：AI 服务密钥保存在你自己电脑里，不上传；也别发给别人或发到网上。
3. **远程连接要 PIN**：连你的电脑需要输入你设的 6 位 PIN 码。
4. **AI 浏览器要守平台规则**：部分网站对自动化操作有自己的规则，请合理使用，遵守平台条款。自动发布/自动回复建议先小范围试跑，确认合适再放量。
5. **进阶能力不用学**：MCP 服务器、技能包、浏览器操作（Browser Action）属于进阶能力，由 IT 统一配置分发，普通员工零配置、也不需要了解。

## 十一、常见问题

**我完全不懂技术，真的能用吗？**
能。安装双击下一步、登录微信扫码、使用就是打字说话，全程不需要知道 AI 模型和服务器的存在。

**我的数据存在哪里？安全吗？**
都在你自己的电脑上。纯本地应用，官方没有存储用户数据的服务器；也可装在公司内网，数据不出门。

**用它要花多少钱？**
软件本身免费开源。微信扫码登录送免费体验额度；重度使用换成自己购买的 AI 服务，费用付给服务商，Meco 不加价。

**和网页版 AI 聊天助手有什么区别？**
网页版只能「聊」，Meco 能「做」：操作浏览器、读写文件、定时干活；干完主动汇报，拿不准先问你。

**AI 干活会不会乱来？**
删除、发送、提交这类敏感操作会先问你。每一次做了什么都有记录可回看。

**会不会很占电脑资源？**
Meco 本身很轻量。AI 的「思考」发生在服务商机房里，你的电脑只负责界面和执行，普通办公电脑跑得动。

**公司能用吗？数据会外泄吗？**
特别适合。支持内网部署、接公司自己的模型服务；IT 统一安装分发，员工开箱即用、不各自付费。

**遇到问题去哪里求助？**
加入官方社区提问；内部可先找本部门的 Meco 联络人（建议每个部门指定一位）。
