# Meco 培训讲师指南

> 配套《Meco企业培训-非技术员工全面上手指南.pptx》（36 页）使用。
> 受众：非技术企业员工。目标：培训结束后，每位学员能独立完成「安装 → 说第一句话 → 看到成果」，并知道数字人、远程和安全的用法与边界。

---

## 1. 课前准备

### 讲师侧

- [ ] 通读本指南与 PPT，对照《Meco使用手册》确认口径一致。
- [ ] 准备一台装好 Meco 的演示电脑（投屏用），已登录、已连好模型服务。
- [ ] 预跑一遍 §3 的三个现场演示，记录实际等待时长（与网络和模型速度有关）。
- [ ] 打印或线上发放《Meco使用手册》，培训后随 PPT 一起发。
- [ ] 如公司有内部规范（涉密处理、自动发布审批等），准备一句话口径，见 §5。

### IT 侧（提前 1–3 天）

- [ ] 确认学员电脑满足系统要求（macOS 11+ / Windows 10+ / Ubuntu 20.04+）。
- [ ] 决定接入方式：微信扫码免费额度（培训现场最顺）或公司统一模型服务。
- [ ] 如走企业微信：管理员提前建好机器人，拿到地址和密钥。
- [ ] 如需内网部署/私有商店：提前完成部署，培训只演示不现场装。

## 3. 现场演示脚本

### 演示 1：三要素提示词生成材料包（对应 PPT 4–5 页，约 4 分钟）

照 PPT 第 4 页的提示词卡，把「示例公司」换成演示环境里的一个真实测试文件夹，现场派活：

> 「生成《示例公司起诉资料包》：起诉状、证据目录、授权委托书，各 1 份 Word；资料在桌面「示例公司」文件夹（合同、欠款明细、主体证明）；要求：引用合同条款原文、金额单位统一、语气正式；完成后打包成一个 zip。」

- 边等边讲三要素：目标材料（产出什么）、材料（在哪）、要求（口径红线）。
- 生成后点开工件栏展示文件；补一刀修改：「金额单位全部改成大写」，展示开口就改。
- **话术**：大家看，我说的每句话都落在三要素上。你们回去套自己的业务，把这三句填满就行。

### 演示 2：提交前先问你（对应 PPT 8 页，约 1 分钟）

讲场景 4 时顺势讲：对外提交、删除、付款这类动作它一定停下来给你选项——PPT 8 页左侧截图就是真实记录（已脱敏）。若时间充裕，可现场让它打开一个公开网站演示操作可见性，**不要**真的提交任何东西。

### 演示 3：数字人上岗（对应 PPT 6 页，约 2 分钟）

打开「数字人」页，指给学员看「需要你处理 / 待命中」两个状态区；再到商店走到「填配置」一步即停，**不要真的安装**。话术：挑一个、填几个空、上岗；先跑只读汇报类。

> 演示纪律：全程不在演示机上输入任何真实账号、密钥、客户资料。

## 4. 每页讲课要点

**P2（场景总览）**：定全场基调——五个场景按「谁干」分好：IT/你配一次、AI 干你验收、数字人自动、AI 操作你确认。主动权永远在人。

**P3（配模型）**：强调「一次配置长期用」，别让学员有心理负担；密钥只存本机一句话带过，统一接入以 IT 通知为准。

**P4–5（提示词，全场重心）**：三要素让学员当场套自己业务口头填一遍（目标材料是什么？材料在哪？要求是什么？）；质量 5 招里「先提纲」「让它自查」最见效，重点讲。

**P6–7（邮箱哨兵）**：先讲痛点（漏邮件、追资料靠人催），再讲「班表」概念——定时检查的间隔按业务节奏定。务必强调先跑「只读 + 汇报」一到两周，再放开代发/提交类动作。

**P8（浏览器代办）**：核心话术是「你登录过一次，它就在你的环境里操作」；演示 2 顺势讲「先问是设计不是故障」；合规条（平台规则、提交支付你点头）必须原样读。

**P9（节点巡检）**：强调付款由你本人完成；「查不到也要报一遍」这条要讲——防止静默漏查造成假安心。

**P10（安全底线）**：四条逐条读原文，不加码。个人微信非官方协议、平台条款两条在答疑里补充。

## 5. 学员常见提问与回答口径

| 提问 | 回答口径 |
|---|---|
| 数据会不会上传到你们服务器？ | 不会。纯本地应用，官方没有存储用户数据的服务器；只有 AI 干活联网时按你配置的服务访问。内网部署可全程不出内网。 |
| 它会不会自己把我文件删了？ | 删除、发送、提交这类敏感操作默认先问你；每次操作有记录可回看。 |
| 免费额度用完怎么办？ | 换自己的 AI 服务账号（设置 → AI 模型），费用付给服务商，Meco 不加价。 |
| 我该选哪家模型服务？ | 日常写作、整理类任务各家主流模型都够用，可以都试试；公司统一接入的以 IT 通知为准。 |
| 微信连接为什么老掉？ | 个人微信走非官方协议，受微信策略影响，偶尔需重新扫码；正式长期使用请用企业微信。建议小号连接。 |
| 能让它自动发小红书吗？ | 技术上可以，但建议先跑「只读 + 汇报」稳定一两周，再逐步放开对外动作，并遵守平台自动化规则。 |
| 和公司的数据合规要求冲突吗？ | 高度敏感资料只在内网实例处理；具体边界以公司规范为准（讲师按 §1 准备的口径补一句）。 |
| 学不会怎么办？ | 会打字就会用；遇到问题先看手册「常见问题」，再找部门 Meco 联络人。 |

**答不上来的问题**：记下来会后确认，不要现场编。所有承诺限于本 PPT 与手册原文。

## 6. 培训后跟进

1. 当天发放：《Meco学员速查卡》+《Meco上手练习卡》+《Meco使用手册》+ 本 PPT（`docs/training/`）。
2. 布置练习节奏：练习卡一天一课，一周过完；第 1 周答疑检查第 1–3 课验收情况。
3. 每部门指定一位 Meco 联络人，作为第一求助入口；练习卡结业任务做满 3 次的学员是候选人。
4. 当场回收《培训反馈问卷》；第 1、4 周各做一次 15 分钟答疑（可线上），第 4 周收结业任务分享。
5. 汇总高频问题反哺本指南、FAQ 页与下一期课程。
