# Meco 培训讲师指南

> 配套《Meco企业培训-非技术员工全面上手指南.pptx》（36 页）使用。
> 受众：非技术企业员工。目标：培训结束后，每位学员能独立完成「安装 → 说第一句话 → 看到成果」，并知道数字人、远程和安全的用法与边界。

---

## 1. 课前准备

### 讲师侧

- [ ] 通读本指南与 PPT，对照《Meco使用手册》确认口径一致。
- [ ] 准备一台装好 Meco 的演示电脑（投屏用），已登录、已连好模型服务。
- [ ] 预跑一遍 §3 的三个现场演示，记录实际等待时长（与网络和模型速度有关）。
- [ ] 打印或线上发放《Meco使用手册》，培训后随 PPT 一起发。
- [ ] 如公司有内部规范（涉密处理、自动发布审批等），准备一句话口径，见 §5。

### IT 侧（提前 1–3 天）

- [ ] 确认学员电脑满足系统要求（macOS 11+ / Windows 10+ / Ubuntu 20.04+）。
- [ ] 决定接入方式：微信扫码免费额度（培训现场最顺）或公司统一模型服务。
- [ ] 如走企业微信：管理员提前建好机器人，拿到地址和密钥。
- [ ] 如需内网部署/私有商店：提前完成部署，培训只演示不现场装。

## 3. 现场演示脚本

### 演示 1：一句话生成周报（对应 PPT 13 页，约 3–5 分钟）

在默认空间（或预建的「培训演示」空间）输入：

> 「帮我整理一份本周部门工作周报：写成 Markdown 文档，包含「本周完成」「进行中」「下周计划」三部分；再做一个简单的 HTML 周报看板页面，一眼能看到三部分内容。」

- 若 AI 反问内容来源，选「用示例模板」继续（这本身就是素材，见演示 2）。
- 生成后点开工件栏里的 `周报看板.html`，展示画布预览。
- 补一刀修改：「把汇报人换成 XXX」「标题换成 XX 部门周报」，展示开口就改。
- **话术**：大家刚才只看到我说了一句话，剩下拆步骤、写文件、调格式都是它做的。你们要做的只有两件事：说清楚、验收。

### 演示 2：拿不准会先问（对应 PPT 14 页，约 1 分钟）

演示 1 过程中若 AI 停下来给选项，顺势讲：注意，它没猜，它问。信息不够它会停下来给选项；删文件、发消息这类敏感动作同样先征求同意。若演示 1 没触发提问，口头讲 PPT 14 的截图即可（截图来自真实使用记录，已脱敏）。

### 演示 3：商店一键上岗（对应 PPT 21 页，约 2 分钟）

打开「商店」页，搜「日报助手」类数字人，走到「填配置」一步即停，**不要真的安装**。话术：挑一个、填几个空、上岗。回去大家可以从「只读 + 汇报」类的装起。

> 演示纪律：全程不在演示机上输入任何真实账号、密钥、客户资料。

## 4. 每章讲课要点

**P4–5（区别与三件事）**：最容易讲快。三件事是全场基调，尤其「主动权在你」——后面安全和数字人章节都回收这条。

**P9–10（界面与空间）**：只需让学员记住「中间派活、右边看成果」。空间的「独立抽屉」比喻足够，不要展开技术细节。

**P12（说清楚）**：让学员现场口头互评一句话够不够具体，比讲师单向讲有效。

**P16（开口就改）**：强调「接着说」——AI 记得上文，不用重述背景。这是和网页版 AI 体感差异最大的点之一。

**P19–22（数字人）**：先讲「班表」比喻，再讲三类用途，最后给放权节奏建议（先只读汇报、再对外动作）。「执行记录」要提：每一步可回查。

**P26（企业微信）**：明确这是管理员一次性操作，员工只需知道群里 @机器人 能干嘛。

**P27（手机远程）**：强调 PIN 码别用生日；「外网访问」默认不开、按需开。

**P29–31（安全）**：逐条读 PPT 上的承诺原文，不要加码。个人微信非官方协议、平台自动化条款这两条必须讲到。涉密口径按公司规范补一句。

## 5. 学员常见提问与回答口径

| 提问 | 回答口径 |
|---|---|
| 数据会不会上传到你们服务器？ | 不会。纯本地应用，官方没有存储用户数据的服务器；只有 AI 干活联网时按你配置的服务访问。内网部署可全程不出内网。 |
| 它会不会自己把我文件删了？ | 删除、发送、提交这类敏感操作默认先问你；每次操作有记录可回看。 |
| 免费额度用完怎么办？ | 换自己的 AI 服务账号（设置 → AI 模型），费用付给服务商，Meco 不加价。 |
| 我该选哪家模型服务？ | 日常写作、整理类任务各家主流模型都够用，可以都试试；公司统一接入的以 IT 通知为准。 |
| 微信连接为什么老掉？ | 个人微信走非官方协议，受微信策略影响，偶尔需重新扫码；正式长期使用请用企业微信。建议小号连接。 |
| 能让它自动发小红书吗？ | 技术上可以，但建议先跑「只读 + 汇报」稳定一两周，再逐步放开对外动作，并遵守平台自动化规则。 |
| 和公司的数据合规要求冲突吗？ | 高度敏感资料只在内网实例处理；具体边界以公司规范为准（讲师按 §1 准备的口径补一句）。 |
| 学不会怎么办？ | 会打字就会用；遇到问题先看手册「常见问题」，再找部门 Meco 联络人。 |

**答不上来的问题**：记下来会后确认，不要现场编。所有承诺限于本 PPT 与手册原文。

## 6. 培训后跟进

1. 当天发放：《Meco使用手册》+ 本 PPT（`docs/training/` 目录）。
2. 每部门指定一位 Meco 联络人，作为第一求助入口。
3. 按手册「30 天上手路线」在第 1、4 周各做一次 15 分钟答疑（可线上）。
4. 收集高频问题反哺本指南与 FAQ 页。
