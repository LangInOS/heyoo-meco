# Meco 企业培训材料包

面向非技术企业员工的 Meco 培训成套材料。讲师拿 PPT + 讲师指南即可开课；学员拿使用手册即可上手。

## 内容

| 文件 | 用途 | 发给谁 |
|---|---|---|

## 学员材料使用顺序

培训当天：速查卡（带走）→ 练习卡（一周一课跟做）→ 卡了查手册；第 4 周答疑时做结业任务分享。

## PPT 结构（12 页 · 一条业务线五个场景）

1. 一条业务线，五个场景（总览：谁配置、谁干、谁确认）
2. 场景 1 配置与选择模型（一次配置、按任务定档位）
3. 场景 2 写好提示词（目标材料 + 材料 + 要求，附可直接抄的示例）+ 质量 5 招
4. 场景 3 邮箱哨兵（配置 + 工作流：新邮件 → 下载 → 审核 → 通知）
5. 场景 4 AI 浏览器代办（法院 / 政府网站上传提交，提交前先问）
6. 场景 5 节点巡检（缴费、开庭不逾期）
7. 四条安全底线 → 一周落地路径 → 结尾
