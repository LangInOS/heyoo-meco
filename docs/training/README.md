# Meco 企业培训材料包

面向非技术企业员工的 Meco 培训成套材料。讲师拿 PPT + 讲师指南即可开课；学员拿使用手册即可上手。

## 内容

| 文件 | 用途 | 发给谁 |
|---|---|---|
| `Meco企业培训-非技术员工全面上手指南.pptx` | 36 页培训主课件，含 10 张脱敏实拍截图与讲师备注 | 讲师投屏 |
| `培训讲师指南.md` | 课前准备、时间分配（60/30 分钟两版）、演示脚本、提问口径 | 讲师 |
| `Meco使用手册.md` | 图文版上手手册：安装、界面、日常用法、数字人、远程、安全、FAQ、术语表 | 学员 |
| `assets/` | 课件引用的截图（均来自真实使用记录，已脱敏） | — |

## PPT 结构（六章）

1. 装好、连上、说第一句话（安装 / 连接 AI / 界面 / 空间）
2. 日常干活：对话 + 画布（说清楚三要素 / 看成果 / 开口就改 / 先问再做）
3. 让 AI 自动干活：数字人（数字人 / 商店 / 面板管理 / 知识库）
4. 出门也能遥控（消息通道 / 企业微信 / 手机远程）
5. 安全与边界（数据本地 / 先问再做 / 合规注意）
6. 上手路径与资源（30 天路线 / FAQ / 术语速查）

## 截图脱敏说明

`assets/` 内截图已做以下处理，替换截图时请重复同样检查：

- 人名与拼音（含文件所有者列）→ 马赛克或替换为 employee
- 邮箱地址 → demo@example.com
- 本地路径中的用户名 → /Users/employee
- 空间/客户等内部名称 → 示例公司、示例客户、项目 A/B 等通用名
- 空间 UUID、私人对话标题 → 马赛克或移除

## 维护

- 产品功能与 UI 名称以 Meco 官方文档为准，更新后同步三份材料。
- 口径原则：普通用户视角行文，不出现代码、命令行、协议名；安全承诺原文呈现、不加码。
