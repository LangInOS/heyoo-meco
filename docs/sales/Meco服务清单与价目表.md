1. **AI 模型调用费客户自付**，由客户直接与模型服务商结算，不含在以上报价内；如需代为筛选模型服务商，见"模型服务代寻"，费用另计。
2. **服务计价按人日标准价 ¥2,000（8 小时 / 人日，折 ¥250 / 小时）核算，本次合作统一按八折执行，即 ¥1,600 / 人日（¥200 / 小时）**。答疑支持为固定总价，不按小时拆分计费。
3. 报价含远程实施；需到场的，差旅实报实销。
4. 付款：合同生效预付 50%，上线并完成培训后付 50%。
5. 运行保障期满未续，则转为按次答疑（¥800 / 次）或按人日结算。
6. 年度维保按人日结算（标准 ¥2,000 / 人日，八折后 ¥1,600 / 人日，年度最低 4 人天），每次上门或远程服务前确认工作量。
